# Default Character Assets

Bundled files under `data/uploads/defaults/`:

- `*.png` — original avatar images (~512px)
- `thumbs/*.webp` — 256px WebP thumbnails served in the UI

## Origin

These images were generated locally with AI image models (anime-style character portraits). The author releases them **with the project for free use** — no third-party copyright claims.

## Replacing avatars

- Upload a new image via the character editor in the UI, or
- Replace files under `data/uploads/defaults/` and restart (thumbnails regenerate on startup if missing).

No ComfyUI or external generator is required to run shanaTavern.
