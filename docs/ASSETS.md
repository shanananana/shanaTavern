# 素材说明 · Default Character Assets

## 文件位置

`data/uploads/defaults/` 目录下：

- `*.png` — 原图头像（约 512px）
- `thumbs/*.webp` — 256px WebP 缩略图（UI 实际加载）

## 来源与许可

头像由作者使用本地 AI 模型生成的动漫风格立绘，**随本项目 MIT 协议一并发布，可自由使用**，不涉及第三方版权。

## 替换头像

- 在角色编辑页上传新图，或
- 直接替换 `data/uploads/defaults/` 下文件并重启（缺失的缩略图会在启动时自动生成）

运行 shanaTavern **不需要** ComfyUI 或任何外部生成工具。

## Bundled files

Under `data/uploads/defaults/`:

- `*.png` — original avatar images (~512px)
- `thumbs/*.webp` — 256px WebP thumbnails served in the UI

## Origin & license

Generated locally with AI image models (anime-style portraits). Released **with this project for free use** — no third-party copyright claims.

## Replacing avatars

- Upload via the character editor in the UI, or
- Replace files under `data/uploads/defaults/` and restart (missing thumbs regenerate on startup).

No ComfyUI or external generator is required.
